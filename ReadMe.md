# FaceAnimationMaker

Unity Editor 上でアバターの BlendShape を調整し、表情用の AnimationClip（`.anim`）を作成するツールです。複製したアバターでプレビューするため、シーン上の元アバターの BlendShape 値を直接変更せずに表情を作れます。

## 主な機能

- アバター全体を表示しながら、選択した顔メッシュの BlendShape を調整
- BlendShape 名の検索、見出しによる折りたたみ、非ゼロ項目の絞り込み
- プレビュー値の Undo / Redo / Reset
- 表情用 `.anim` の新規作成、既存クリップへの保存、既存クリップからの値の読み込み
- プレビューの回転・移動・ズーム、左右ペインの幅調整

## 導入

BlendShape を持つ `SkinnedMeshRenderer` と、そのメッシュ・マテリアルを含む Unity プロジェクトで使用します。このツールのコード自体は VRChat SDK に依存していません。

1. このリポジトリの `editor` フォルダーを、Unity プロジェクトの `Assets/FaceAnimMaker/Editor/` にコピーします。分割されたすべての `.cs` ファイルをまとめて配置してください。
2. Unity のスクリプトコンパイルが完了するまで待ちます。
3. メニューの **Tools > LastMemories > FaceAnimationMaker** を開きます。

Unity の対応バージョン範囲は、このリポジトリでは定義していません。

## 表情を作成する

1. **Avatar Root** にアバターのルートオブジェクトを指定します。保存するアニメーションを再生する Animator のルートに合わせてください。
2. **Face Mesh** で、表情を調整する `SkinnedMeshRenderer` を選びます。
3. 右側の BlendShape スライダーを調整します。操作範囲は **0～100** です。
4. **Create .anim** を押し、プロジェクト内の保存先を指定します。新しいクリップを作成し、現在のプレビュー値を保存します。

**Selected Face Mesh** へ直接メッシュを指定することもできます。Hierarchy で `SkinnedMeshRenderer` が付いたオブジェクトを選択した場合も、対象メッシュに反映されます。このとき Avatar Root は対象オブジェクトの最上位ルートに設定されるため、親に管理用オブジェクトがある場合は Avatar Root を確認してください。

### プレビュー操作

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 回転 |
| 右ドラッグ | 上下左右へ移動 |
| マウスホイール | ズーム |
| ダブルクリック | 正面表示と自動フィットに戻す |
| 左右ペインの境界をドラッグ | ペインの幅を変更 |

### BlendShape 一覧

- **Search**：名前の部分一致で検索します。大文字・小文字は区別しません。
- **Foldout Delimiter**：グループ見出しを判定する区切り文字です。初期値は `-` で、例えば `--------Eye--------` を見出しとして扱い、後続の項目をまとめます。
- **Show Non-Zero BlendShapes**：押した時点で値が非ゼロの項目に絞り込みます。編集中は表示対象が固定され、**確定（非ゼロ一覧を更新）** で再判定します。
- **Show All BlendShapes**：非ゼロの絞り込みを解除します。

`vrc.` で始まる BlendShape は、大文字・小文字を問わずリップシンク用として一覧から除外されます。

### 履歴とリセット

- **Undo / Redo**：ツール内のプレビュー値を戻す・やり直す操作です。
- **Reset**：選択中の元メッシュの現在の BlendShape 値へ戻します。すべてをゼロにする操作ではありません。

## 既存の AnimationClip を使う

**Animation Clip** に既存のクリップを指定して、次の操作を行います。指定しただけでは値は読み込まれません。

- **Load .anim Values**：選択中のメッシュに対応する BlendShape カーブの **0 秒時点**の値を読み込みます。対応するカーブがない項目はゼロになります。
- **Save Preview Values**：現在のプレビュー値を指定したクリップへ保存します。対象メッシュの対応するカーブを更新するため、元の表情を残す場合は先にクリップを複製してください。

### 保存される内容

- 対象は、選択中の **1 つの SkinnedMeshRenderer** の BlendShape です。
- カーブのパスは **Avatar Root から対象メッシュまでの相対パス**です。読み込み時も同じ階層構成が必要です。
- 各値は、0 秒から `1/60` 秒までの一定値カーブとして保存します。新規クリップのフレームレートは 60 fps です。
- 通常の BlendShape は、値がゼロでも保存します。
- `vrc.` で始まる BlendShape は、ゼロの場合は対応カーブを削除し、非ゼロの場合は保存します。一覧で非表示でも保存対象になり得ます。
- 対象外のメッシュやプロパティのカーブは、そのまま残ります。

作成したクリップは、利用先の Animator Controller などへ別途設定してください。

## 使用上の注意

- 対象メッシュの切り替えやプレビューの再生成で、調整値とツール内の履歴は初期化されます。残したい表情は先に `.anim` へ保存してください。
- 調整値の自動保存機能はありません。ウィンドウを閉じる前にも保存してください。
- 顔が見つからない場合は、選択したメッシュに BlendShape があるか確認してください。項目が見えない場合は検索・非ゼロフィルター・折りたたみ状態も確認してください。
- 既存クリップから値を読み込めない場合は、Avatar Root と対象メッシュの相対パスが、クリップのカーブと一致しているか確認してください。

## ソース構成

`editor/FaceAnimMakerPreviewWindow*.cs` は、同じ `partial` クラスを機能別に分割したものです。ウィンドウ本体、対象選択、プレビュー生成・描画・範囲計算、BlendShape 一覧、履歴、AnimationClip の入出力、ペイン操作で構成されています。
